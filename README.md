## Hi there 👋

I'm Russ. I've been working in IT for a while now. I started on the help desk at Intel and Apple, and moved to desktop support and field services for MSPs, then to Systems and Network administration.

My areas of interest include infrastructure design, deployment, and management. This includes on premises, cloud, and hybrid architectures. Additionally, I'm interested in cloud, cyber-security, automation, and practical use-cases for AI.

I like exploring different approaches to technology use. For example, I got opportunity to implement Chromebooks and Google Workspace at a company that was , up til then, an all-Windows environment. A lot of the Windows machines were only used to access a Citrix desktop environment. So getting to explore the Chrome ecosystem and setting up the sync between AD and Google Workspace, automating enrollments, wireless profiles and application provisioning(including Citrix Workpace), etc., and seeing the improvements in user experience was awesome.

I use AI mainly as a research/study assistant. I've found it useful to bounce ideas off of if I run into an issue on a project I'm working on. I'm not a vide-coder, and I'm not willing to hand off my critical thinking and creativity to AI.

When I'm not doing IT stuff (work, labbing, or learning) I get outside and do trail running and hiking. If I have any extra free time, I like to play a bit of Fallout (3, 4, London, it all good!).
